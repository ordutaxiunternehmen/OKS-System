COCKPIT PLUSADMIN
DEMO-Modus – erfundene Beispieldaten. Im Echtbetrieb kommen hier eure echten Mitglieder und Zahlungen an.

Admin-Anmeldung

Nur für die Inhaber. Zugang mit Passwort und Code aus der Authenticator-App.

Zwei-Faktor einrichten

Einmalig: Scanne den Code mit einer Authenticator-App (z. B. Google Authenticator, Microsoft Authenticator) und gib den 6-stelligen Code ein.

Oder manuell:

Code eingeben

6-stelliger Code aus deiner Authenticator-App.

Ampel: bezahlt Zahlung offen / Frist läuft gesperrt Zahlung nicht eingerichtet / gekündigt. Status und Sperren laufen automatisch über Mollie – hier könnt ihr bei Bedarf eingreifen.
